# 纯Triton实现SVD算子优化计划

## 一、技术方案选择

### 算法选择：单边Jacobi SVD算法

**选择理由**：

1. **天然并行性**：Jacobi算法可以并行处理多对列，适合GPU架构
2. **数值稳定性**：Jacobi算法具有高精度和良好的数值稳定性
3. **GPU友好**：相比QR方法，Jacobi算法更适合在GPU上实现
4. **已有研究**：基于GPU的两层并行块Jacobi SVD算法在V100上比cuSOLVER快1.8倍

### 算法原理

**单边Jacobi SVD算法**：

```
输入：矩阵 A (m × n)
输出：U, S, V 使得 A = U @ diag(S) @ V^T

步骤：
1. 初始化：B = A, V = I
2. 迭代直到收敛：
   a. 选择列对 (i, j)
   b. 计算2×2子矩阵的SVD
   c. 计算旋转角度 θ
   d. 应用Jacobi旋转：B[:, [i,j]] = B[:, [i,j]] @ R(θ)
   e. 更新V：V[[i,j], :] = R(θ)^T @ V[[i,j], :]
3. 提取奇异值：S = ||B[:, i]||₂
4. 归一化：U = B / S
```

## 三、实现细节

### 3.1 Jacobi旋转计算

**数学推导**：

```
给定列向量 bi, bj
计算：
  a = ||bi||²
  b = ||bj||²
  c = bi · bj
  
旋转角度：
  τ = (b - a) / (2 * c)
  t = sign(τ) / (|τ| + sqrt(1 + τ²))
  cos θ = 1 / sqrt(1 + t²)
  sin θ = t * cos θ
```

### 3.2 并行扫描模式

**策略**：将n列分成n/2对，并行处理

```
迭代1: (0,1), (2,3), (4,5), ...
迭代2: (1,2), (3,4), (5,6), ...
迭代3: (0,1), (2,3), (4,5), ...
```

### 3.3 收敛加速

**动态容差**：

* 初始容差：`tol = 1e-6`

* 根据矩阵条件数调整

* 使用相对容差：`tol * max(S)`

## 六、风险与挑战

### 6.1 技术挑战

1. **收敛性**：Jacobi算法可能需要多次迭代
2. **数值稳定性**：处理奇异值接近零的情况
3. **内存限制**：大矩阵需要分块处理

### 6.2 解决方案

1. **优化扫描策略**：使用动态排序加速收敛
2. **混合精度**：关键步骤使用高精度
3. **分块算法**：对大矩阵使用分块Jacobi
